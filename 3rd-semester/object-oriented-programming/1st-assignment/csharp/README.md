# Assignment 1 — Surveillance Registry (C#)

C# port of the Java surveillance registry assignment.
Same domain, idiomatic C# .NET 8 — abstract classes, LINQ, ILogger<T>.

## Course
Object-Oriented Programming — Semester 3

## Language
C# 12 / .NET 8 — Console application

## How to Run

### Prerequisites
- .NET 8 SDK

### Steps
```bash
cd 1st-assignment/csharp
dotnet run
```

## What It Demonstrates
- Abstract classes and sealed subclasses
- Nullable reference types, `IReadOnlyList<T>`
- LINQ (`Where`, `MaxBy`, `Cast`)
- `Microsoft.Extensions.Logging` with `ILogger<T>` constructor injection
- XML documentation comments on all public members
