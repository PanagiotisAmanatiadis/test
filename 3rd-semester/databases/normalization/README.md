# Normalization

Normalization exercises covering BCNF, 3NF, and 4NF decomposition of relational schemas.

## Course
Databases — Semester 3

## Language / Format
PDF report

## Contents

| File | Description |
|------|-------------|
| `BCNF-3NF-4NF.pdf` | Full normalization report with functional dependency analysis |

## What It Demonstrates
- Identifying functional dependencies and candidate keys
- Decomposing schemas to Boyce-Codd Normal Form (BCNF)
- Lossless-join and dependency-preserving decomposition to 3NF
- Multi-valued dependencies and 4NF decomposition
