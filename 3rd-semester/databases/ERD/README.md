# Entity-Relationship Diagrams

Two ER diagram exercises modelling real-world database schemas using the Chen/crow's-foot notation.

## Course
Databases — Semester 3

## Language / Format
PNG diagrams (hand-drawn / diagramming tool exports)

## Contents

| File | Description |
|------|-------------|
| `q1.png` | ER diagram for exercise 1 |
| `q2.png` | ER diagram for exercise 2 |

## What It Demonstrates
- Entity and attribute identification
- Relationship types (one-to-one, one-to-many, many-to-many)
- Primary key selection and cardinality constraints
