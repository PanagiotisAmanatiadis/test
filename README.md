# BSc Applied Informatics — Undergraduate Coursework

A curated collection of programming assignments completed during my
Bachelor of Science in Applied Informatics degree at the University of Macedonia.

All assignments have been refactored to reflect professional, enterprise-grade coding standards.

## Languages Used
- Python
- C++
- C# (.NET)
- Java
- Solidity + JavaScript (React / Web3)
- SQL

## Semesters & Courses

### Semester 1
- **Procedural Programming**: Fundamental C++ programming — arrays, pointers, structs, file I/O, and algorithm design through a series of incremental exercises.
- **Algorithms**: Classic algorithmic problems implemented in Python — sorting, searching, and combinatorial exercises.

### Semester 2
- **Data Structures**: Linked lists, stacks, queues, trees (BST, AVL, Huffman), hash tables, and sets implemented in C++17 with RAII and modern OOP design.

### Semester 3
- **Databases**: Relational database design — ER diagrams, normalisation (1NF–BCNF), relational algebra, and SQL queries.
- **Object-Oriented Programming**: OOP principles in Java and C# — encapsulation, inheritance, polymorphism, and design patterns applied to real-world modelling exercises.

### Semester 4
- **Human–Computer Interaction**: Interactive application prototypes (EDIT, ROBIE, ROOM, SPACEMAN) demonstrating usability principles and interface design.

### Semester 5
- **Web Services**: Client–server web application development with REST APIs.

### Semester 6
- **Artificial Intelligence**: Search algorithms in Python — A\*, IDA\*, and heuristic evaluation applied to Free-Cell Solitaire, Peg Solitaire, and the Knuth Mastermind solver.
- **Cloud Computing**: Cloud architecture assignment covering deployment, scalability, and managed services.
- **Parallel & Distributed Computing**: Ten C# (.NET 8) lab exercises covering threads, race conditions, mutual exclusion (Dining Philosophers), Producer–Consumer, data parallelism, Pi approximation, string matching, histogram, Sieve of Eratosthenes, divide-and-conquer, TCP client–server, and gRPC.

### Semester 7
- **Information Retrieval**: Movie recommender system in Python implementing User-Based CF, Item-Based CF, and SVD collaborative filtering with cosine similarity and Pearson correlation.
- **Knowledge Discovery from Databases**: Instance selection algorithms (IB2 and ENN) implemented as a Python OOP package with vectorised k-NN and batch sklearn NearestNeighbors.

### Semester 8
- **Applied Numerical Analysis**: (1) Anti-missile defence simulation with RK4 ODE integration and intercept geometry; (2) 3-D Signed Distance Field computation via the Fast Marching Method.
- **Blockchain**: Three Solidity smart contracts (Bidder, token-based Lottery with stage machine) and a React + Web3.js dApp for a 3-prize lottery deployed to GitHub Pages.

## Code Quality Standards Applied
- Object-Oriented Programming (encapsulation, inheritance, polymorphism, abstraction)
- Design Patterns (Factory, Strategy, Observer, Repository, Singleton, …)
- Structured logging — no raw `print` / `Console.WriteLine` output
- Type safety and null safety
- Full docstrings and API documentation
- Conventional Commits version control
